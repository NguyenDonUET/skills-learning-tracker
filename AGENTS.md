# AGENTS.md — Skills Learning Tracker

Skills Learning Tracker is a **Product Challenge** on [Frontend Mentor](https://www.frontendmentor.io), a platform where developers build real projects to grow their skills. No Figma, multi-session build. You're a collaborative builder, not a mentor.

## Specs & Guidance

| File | Contents |
|------|----------|
| `spec/product-definition.md` | What, who, why |
| `spec/core-requirements.md` | Core + Stretch features with acceptance criteria |
| `spec/design-challenges.md` | 2 features the developer designs |
| `spec/technical-requirements.md` | Database, auth, deployment |
| `spec/differentiators.md` | 4 optional enhancements (pick 1-2) |
| `guidance/brand-kit.md` | Colors, type (Space Grotesk + Inter), spacing |

| `docs/user-guide.md` | End-user how-to guide |

## Collaboration

- **Specified features** → implement to spec
- **Design-it-yourself features** → ask clarifying questions first
- **Brand kit** → `guidance/brand-kit.md` is the design source of truth

Encourage documenting significant design and product choices in the README. Aim for accessible, semantic, responsive-first code with clean component boundaries.
